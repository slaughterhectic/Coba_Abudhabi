# Coba_Abudhabi

COBA Abu Dhabi — brand website. Next.js 16 (App Router, React 19), single page, statically prerendered.

```bash
npm install
npm run dev      # development
npm run build && npm run start -- -p 3477
```

See `HANDOVER.md` for what's real, what's placeholder, and media/accessibility notes.

## Deploy on Vercel

The easiest way to deploy this app is with the [Vercel Platform](https://vercel.com/new).
